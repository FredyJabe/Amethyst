What makes Amethyst different

A new foundation for familiar worlds.

Amethyst implements its own server engine rather than wrapping or modifying the vanilla server. Here's what's already taking shape.

01

Native Java protocol

Minecraft Java Edition 26.3 connection handling, authenticated login, chunk streaming, and player synchronization.

02

Procedural Overworld

Seeded continents, mountains, biomes, caves, aquifers, trees, ores, and small structures from a custom generator.

03

Shards plugin system

Extend behavior through lifecycle hooks, services, capabilities, packet hooks, and command registration.

04

Creative & Survival

Experimental mining, block placement, physical item drops, item pickup, and inventory management.

05

Items & workstations

YAML-defined items and recipes, plus early crafting-table, furnace, smoker, and blast-furnace support.

06

World persistence

Persisted generated worlds, block edits, player locations, inventories, and workstation contents.

The Shards architecture

A small core. An expandable universe.

The Amethyst core focuses on connections, communication, and Minecraft packets. Shards provide world generation, item definitions, gameplay, and other server capabilities without hardwiring everything into the engine.

Build your own Shard or explore the bundled implementations and their APIs.

Start exploring

Build it. Run it. Make it yours.

The source is public and ready for contributors and curious developers. Clone the repository, build the solution, and start your own local test server.

  • .NET 10 SDK
  • Minecraft Java Edition 26.3 client
  • Authenticated Java account for joining
Quick startbash
# Clone and build
git clone https://github.com/FredyJabe/Amethyst.git
cd Amethyst
dotnet build Amethyst.slnx

# Run with the default configuration
dotnet run --no-build --project src/Amethyst.csproj -- server.yaml

On Linux/macOS, you can also run ./run.sh. For configuration and setup details, see the project README.

Prototype status

Amethyst is experimental and not production-ready. Gameplay, vanilla compatibility, lighting, and some server mechanics remain incomplete. It's a project to build, test, explore, and improve — not a drop-in replacement for a fully featured Minecraft server.
